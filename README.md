# 云枢 AeroFire · 公开作品集

低空消防设施规划与多情景决策：风险地图、选址优化、避障路径、方案对比、审核备注和报告导出。

**公开版只使用独立生成的虚拟城区数据。没有从研究原文件抽样、平移或扰动坐标，不包含真实设施布局、火灾记录、风险表、Notebook、个人信息或原运行数据库。** 生成器不读取任何原研究输入。本地原版与公开版完全分开。

## 本地运行

```sh
pip install -r requirements.txt
cd frontend
npm ci
npm run build
cd ..
python run.py
```

打开 http://127.0.0.1:8765 。也可在本目录运行 `docker compose up --build`。

## 发布成网页

仓库根目录的render.yaml可由Render的New → Blueprint导入，或创建Docker Web Service。后端与前端同源部署，支持完整规划计算。健康检查为/api/ready，地图初始化完成前返回503。

默认配置不挂载付费磁盘，数据库和方案属于当前展示实例，重启或重新部署后可能重置。多人访问共用此展示实例，不输入真实业务数据或私密审核意见。若需持久化或更多计算资源，在托管平台自行选择配置；本项目未自动购买服务。空间计算的资源需求应以实际部署测量为准。

## 虚拟数据

运行 `python generate_public_data.py` 可重新生成全部公开数据：229个候选点、1600个风险网格、420个八时段需求及示意建筑。数据固定随机种子。坐标仅用于地图绘制，不代表真实城市中的对象。输入数据版本更新后应清理本项目生成的路径缓存。

原算法的150米栅格避障、风险覆盖贪心与固定种子遗传改进、风险优先巡检路线保留。结果仅用于展示交互和方法，不得用作实际消防配置或飞行指令。

## 真实数据权限

真实数据仅保留在原本地项目，不在此仓库，也不随Docker镜像上传。要对外提供真实数据，应另建私有实例、独立数据库和登录权限；不能把真实文件加入公开Git历史后再用前端按钮隐藏。
